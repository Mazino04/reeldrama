⚙️ CORS Proxy Settings

Direct fetch to narto-drama.com is tried first (no proxy). If blocked by CORS (GitHub Pages), the app automatically falls back to AllOrigins then CodeTabs. You can override this here.

Narto Drama requires an active account session to search external providers like Dramabox. If you have an account, paste your session cookie here to allow proxy searches, or enable CORS in your browser.

🔥 Firebase Setup Required

To enable Google Sign-In and cloud watch list syncing, please configure your Firebase project:

  1. Open the file firebase-config.js in your project.
  2. Replace the placeholder keys in firebaseConfig with your credentials from the Firebase Console.
  3. Enable Google Sign-in in Authentication > Sign-in method.
  4. Create a Cloud Firestore database.

A full step-by-step walkthrough is provided in the assistant chat guide.
